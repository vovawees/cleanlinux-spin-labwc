# Безопасность

Нашли уязвимость в **cleanlinux-spin-labwc**? Не открывайте публичный issue: сообщите приватно через
[Report a vulnerability](https://github.com/vovawees/cleanlinux-spin-labwc/security/advisories/new) (вкладка Security).
Опишите, что затронуто, как повторить и какие версии проверены. Ответ — в течение нескольких дней;
исправление выходит новым релизом и рецептом с `security=(…)`, который берёт `burn update --security`.

Поддерживается последний релиз и ветка `main`.

*English: report vulnerabilities privately through GitHub's "Report a vulnerability" (Security tab), not in a public issue.
Fixes ship as a new release and a recipe listing the advisories in `security=()`, which `burn update --security` picks up.
The latest release and `main` are supported.*
